# Monster Camp 한국어판 실게임 검증 체크리스트

**상태: 사용자 실게임 플레이 테스트 완료 (2026-10-25, 사용자 보고).** 다만
체크리스트 항목별 결과·스크린샷·로그는 저장소에 별도로 기록되지 않았다.
아래 체크박스는 세부 재현 기록용이며, 체크되지 않은 항목을 통과로 간주하지
않는다. 자동 `audit`/`build` 및 Unity TextAsset 인메모리 렌더링만으로는
화면 표시 검증을 대신할 수 없다.

## 사전 준비

1. 설치본이 **Monster Prom 2: Monster Camp**인지 확인한다(1편 제외).
   `python -X utf8 build_mod.py` 실행이 통과해야 한다.
2. `build/MonsterCampKR/Localization.txt`와 `manifest.json`의 SHA-256을
   대조한다. 정상 기준은 33,818개의 서로 다른 native ID, 1행당 TAB 1개,
   UTF-8 BOM 없음, `requires_asset_patch` 19건이다.
3. 테스트 전 원본 `MonsterCamp.exe`, `texts_assets_all.bundle`의 해시를
   기록한다. 두 파일을 덮어쓰거나 재패킹하지 않는다.
4. 1편의 사용자 데이터와 혼동하지 않는다. 기존 사용자 모드/세이브가 있다면
   먼저 백업하며 `mods.mpd`를 직접 편집하지 않는다.

## 공식 모드 등록·활성화 확인

- [ ] 게임 내 **Fan Translation Modtool**에서 새 모드 이름을 입력하고
      한국어(`language_korean`, `ko`)를 선택한다. `ModTool.CreateMod`가
      모드 ID와 `Descriptor.mcmtd`를 실제 생성했는지 확인한다.
- [ ] 도구의 **파일 첨부 UI**에서 빌드된 `Localization.txt`를 선택한다.
      `ModPublisherView` / `UiAttachFileButton`이 지정 파일을
      `Mods/<모드 ID>/Localization.txt`로 복사·검증하는 것이 공식 경로다.
      수동으로 `mods.mpd`를 편집하거나 임의의 descriptor를 만들어서는 안 된다.
- [ ] 한국어 번역 모드를 실제 활성화할 수 있는지 별도 확인한다.
      **Load Translation Mod** 목록은 Steam 구독·설치 상태 및
      `mods.mpd`와 연계된다. 로컬 `Descriptor.mcmtd`만 생성됐다는
      이유로 활성화됐다고 간주하지 않는다.
- [ ] Steam 게시가 필요하더라도 별도 승인·공개 범위 검토 없이
      `Publish`를 실행하지 않는다. 실제 활성화 방법과 결과를
      스크린샷이나 로그로 남긴다.
- [ ] 모드 비활성화, 게임 재실행 및 재활성화가 재현 가능하다.

**주의:** 사용자의 플레이 테스트는 실제 게임에서 확인한 근거로 기록한다.
다만 이 저장소에는 공식 GUI의 모드 생성·첨부·활성화 단계와 각 테스트 장면의
세부 결과가 별도 증빙으로 정리되어 있지 않다. 아래 항목을 재현하거나 추가
검증할 때는 모드 ID를 임의 생성하거나 `Mods`에 미등록 파일만 복사한 것을
성공으로 판정해서는 안 된다.

## 화면 스모크 테스트

- [ ] 메인 메뉴·설정·모드 선택 UI가 한글로 보이고 깨진 글리프가 없다.
- [ ] 프롤로그와 기본 이벤트의 지문·캐릭터 말투·선택지 모두 한글이다.
- [ ] 본편에서 성공과 실패 각각의 대사, 능력치 `+/-` 표기가 정상이다.
- [ ] 러브로그·소문·아이스브레이커·음료 이벤트와 엔딩을 대표 표본으로 확인한다.
- [ ] `%CURRENTPLAYERNAME%`, `%HISHER%`, `[n]` 등의 치환/표시가 정상이다.
- [ ] 긴 대사·선택지에서 한글 글꼴, 줄바꿈, UI 넘침/잘림이 없다.
- [ ] 캘큘레스터 엔딩의 `<...>` 진단 로그가 의도대로 표시된다.
- [ ] 스크린샷과 게임 버전, 활성화한 모드 ID, 검증한 이벤트·분기를 기록한다.

### 한글 글꼴 정적 검사에서 남은 화면 확인 사항

설치본에는 `language_korean` 프로필(`id=korean`, `shortCode=ko`)과
`fontset_korean`이 존재한다. 타이틀용 **Jua** 및 본문용 **GamjaFlower**
폰트가 연결되어 있다. 폰트 내부 문자표를 읽기 전용 검사한 결과,
GamjaFlower는 한글 완성형 **11,172/11,172자**를 지원해 현재 번역
33,837개의 한글 음절 중 누락된 것이 없었다. 반면 Jua에는 현재 번역에
실제 쓰인 한글 음절 **4종**이 없어 총 **8개 문구/9회** 사용분에서
제목 표시·대체 글꼴 여부가 미확정이다. GamjaFlower에는 한글 외 문자
**24종/51회** 사용분에 대한 글리프가 없으며, 다른 글꼴로 대체될지는
실게임에서 확인해야 한다. 글꼴 원본 파일을 배포 자료로 포함하지 않는다.

캘큘레스터 엔딩 `success_calculester3_PRE_4/5`의 꺾쇠 괄호 진단
문구는 정적 IL 분석상 엔진 태그가 아닌 일반 대사로 확인됐다. 바깥
`<...>`를 유지하면서 내부를 한국어로 옮긴 현재 형태를 불필요하게
되돌리지 않는다. **실제 글자 표시 결과는 여전히 미검증**이다.

## 적용 범위의 예외와 종료 기준

- **native ID가 없는 19개 행:** 번역 JSON은 완성됐으나 표준
  `Localization.txt`에 들어가지 않는다. 음료 14행, `antterrarium2` 3행,
  `strandedinthelake` 1행, `bandrehearsal` 1행. 별도의 검증된 가역적
  TextAsset/Addressables 로더 없이 **해결된 것으로 표시하지 않는다**.
- **원본 숫자 6개와 `bp_miloyolo3` 플레이스홀더 7개:** 엔진 값이므로
  원형 보존이 정상이다.
- **그림에 인쇄된 영어:** `Localization.txt` 적용 대상이 아니며
  [IMAGE_LOCALIZATION_AUDIT.md](IMAGE_LOCALIZATION_AUDIT.md) 참고.
- 정상 철수 시 공식 도구에서 모드를 비활성화하고,
  게임 원본의 사전·사후 해시 일치를 확인한다.

사용자 플레이 테스트는 완료됐지만, 공식 등록·화면 스모크 테스트의 항목별
기록과 예외 19행·이미지 현지화는 별도 검증 범위다. 따라서 **게임 전체가
모든 상황에서 완벽하게 한국어 표시된다는 주장은 하지 않는다.**
