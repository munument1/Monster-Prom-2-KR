# Monster Camp 한국어 번역 v0.1.0-playtest.2

**실게임 적용·화면 검증 전 테스트 빌드입니다. 정식 안정판이 아닙니다.**

## 이번 업데이트

- 대사에 영문으로 노출되던 능력치 코드를 한국어 이름으로 통일했습니다.
- 빨강·노랑·초록·파랑 주인공 이름 변수 뒤의 조사 오류 약 290곳을 교정했습니다.
- 주인공 색상 지칭과 소문·엔딩 일부 문장의 어색한 표현을 다듬었습니다.
- 번역 지침에 능력치·주인공 조사 규칙을 추가하고 회귀 테스트를 보강했습니다.

## 포함 범위

- 번역 가능한 원문: 33,837 / 33,837개
- `Localization.txt`의 공식 번역 ID: 33,818개
- 원본에 native 번역 ID가 없는 19개 문장은 텍스트 오버라이드에서 제외됩니다.
- 원본 숫자 6개와 내부 플레이스홀더 7개는 의도적으로 보존됩니다.
- 자동 테스트 17개 통과, 전체 번역 카탈로그·토큰 검사 통과, 프리뷰/모드 빌드 통과.

## Steam Workshop에 업데이트할 때

ZIP을 풀어 `Localization.txt`를 사용하세요. 게임 안의 **Fan Translation Modtool**에서 한국어 번역 모드를 만들거나 기존 모드를 업데이트하고, 공식 도구의 번역 파일 첨부/선택 기능으로 이 파일을 지정해 다시 게시합니다. ZIP 자체를 게임 원본 폴더에 덮어쓰지 마세요.

한글 글꼴, 모드 활성화, 실제 대사 표시·줄바꿈은 아직 인게임 검증이 필요합니다. 원본 게임 번들·실행 파일·DLL은 포함하지 않습니다.
